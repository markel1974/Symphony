This project is a high-fidelity emulation of the **MOS Technology 6581 Sound Interface Device (SID)**, the iconic sound chip from the Commodore 64, written entirely in Go. It aims to accurately replicate the behavior and sonic nuances of the original chip by modeling the physical processes of sound generation, providing a robust and performant component for integration into larger emulation frameworks.

## Key Features

This emulator implements all key features of the SID 6581 with a state-of-the-art focus on fidelity.

* **Three Independent Voices**: Each of the three voices is a complete and programmable oscillator with its own frequency, pulse width, and ADSR envelope parameters.

* **Physically Modeled Waveforms**: Instead of simple approximations, waveforms are generated by simulating the SID's internal hardware logic for maximum authenticity.
  * **Triangle:** The waveform is generated by modeling the phase accumulator's MSB-XOR behavior, resulting in the correct, slightly asymmetrical triangle wave characteristic of the 6581.
  * **Sawtooth:** The waveform is physically modeled by performing a bitwise `AND` of the Triangle and Pulse oscillators' internal output, accurately replicating the hardware process and its unique harmonic content.
  * **Pulse:** A perfect, variable-width pulse wave is generated via a direct digital comparison, reflecting the hardware's own logic.
  * **Noise:** A 23-bit Linear Feedback Shift Register (LFSR) with the correct polynomial taps (bits 22 and 17) generates the SID's characteristic pseudo-random noise.
  * **Combined Waveforms:** All combinations (Triangle+Saw, Saw+Pulse, etc.) are calculated in real-time with a bitwise `AND` of the high-fidelity base waveforms, ensuring a rich and accurate harmonic result.

* **High-Fidelity ADSR Envelope Generators**: Each voice features a complete Attack/Decay/Sustain/Release envelope generator, including a precise simulation of the SID's characteristic non-linear decay/release curves.

* **Full Inter-Voice Modulation**:
  * **Oscillator Synchronization**: Accurately modeled to create complex, metallic, and harmonic-rich sounds.
  * **Ring Modulation**: Correctly applies ring modulation to the triangle waveform.

* **Multi-Mode Resonant Filter**:
  * A highly detailed IIR filter model implements Low-Pass, Band-Pass, and High-Pass modes.
  * Handles all 8 filter combinations, including a dynamic-width Notch filter (LP+HP).
  * Includes filter stabilization logic to prevent self-oscillation at high resonance settings.

* **Accurate `TEST` Bit Handling**: The `TEST` bit correctly freezes the oscillators and resets their phase in a way that is faithful to the real hardware, a critical detail for advanced demo compatibility.

## Architecture and Design

The emulator was designed with modern software engineering principles that separate complex, one-time calculations from the performance-critical real-time audio path.

* **"JIT-like" Architecture**: The design mirrors that of a Just-In-Time (JIT) compiler.
  1.  **"Compilation" Phase:** During initialization (`init()`), complex mathematical models of the hardware are executed once to programmatically generate high-resolution, high-fidelity lookup tables (LUTs) for waveforms and envelope rates.
  2.  **"Optimized Execution" Phase:** The real-time audio generation path is extremely fast, as it only needs to perform simple lookups into these pre-compiled tables.

* **Dispatch Table Pattern**: Throughout the package, state-based decisions (waveform selection, envelope state, filter type, register handling) are implemented using **dispatch tables (arrays of functions)**. This architectural pattern eliminates branching from the hot path, dramatically improving performance and code clarity.

* **Component-Based ("Headless") Design**: As indicated by `factory.go`, this package is designed as a "headless" component for integration into the Symphony emulation framework. The core SID logic is completely decoupled from any specific audio driver.

## File Structure

* `mos6581.go`: Contains the core `SID` component, register handling, voice mixing, and the final audio buffer generation loop.
* `voice.go`: Implements a single SID `Voice`, with all logic for waveform generation and ADSR envelope management.
* `filters.go`: Implements the multi-mode resonant filter.
* `tables.go`: Contains constants and the `init()` logic that programmatically generates all necessary lookup tables from mathematical models.
* `mos6581_reflect.go`: Provides the reflection API for debugging and introspection via the Symphony console.
* `factory.go`: Implements the factory pattern for integration into the Symphony framework.
* `interpolations.go`: Provides utility functions.
* `ARCHITECTURE.md`: Describes the SID register map.
